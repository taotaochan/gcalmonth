プライバシーポリシー

GCalMonthWidget（iOS アプリとウィジェット）／ 制定日: 2026年11月11日

1. 取得する情報

Google でサインインしたときに、本アプリが求める権限は次の 1 つだけです。

  • https://www.googleapis.com/auth/calendar.readonly（カレンダーの読み取り専用）

この権限で、カレンダーの一覧（名前・色・表示の設定）と、予定（タイトル・日時・色・終日かどうか・予定の種類・自分の出欠の返答）を読み込みます。予定の作成・変更・削除はしません。

2. 使い方

読み込んだ情報は、ウィジェットとアプリの画面に予定を表示するためだけに使います。広告、分析、機械学習の学習などには使いません。

3. 保存する場所

  • Google のアクセストークンとリフレッシュトークン: 端末のキーチェーン（アプリとウィジェットで共有）
  • 表示用に保存する予定（最大 4 か月分）と、表示中の月の設定: 端末内の、アプリとウィジェットの共有領域

これらを本アプリが端末の外に送ることはありません（iPhone のバックアップに含まれることはあります）。

4. 第三者への提供

開発者のサーバーはなく、本アプリが通信する相手は Google（サインインと Google Calendar API）だけです。取得した情報を、開発者や第三者に提供・販売することはありません。

5. 削除とアクセスの取り消し

アプリの「サインアウト」で、端末に保存したトークンと予定を削除し、Google 側の許可も取り消します。また、Google アカウントの設定（https://myaccount.google.com/permissions）から、いつでも本アプリのアクセスを取り消せます。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

7. 変更

このポリシーを変更するときは、このページを更新します。

8. お問い合わせ

GitHub の Issues からお願いします。

English

Data we access. The app requests only https://www.googleapis.com/auth/calendar.readonly. It reads your calendar list (name, color, visibility) and events (title, time, color, all-day flag, event type, and your own RSVP status). It never creates, changes, or deletes events.

How we use it. Only to display your events in the widget and the app. Not for ads, analytics, or training machine-learning models.

Storage. OAuth tokens are kept in the iOS Keychain, shared between the app and its widget. Up to four months of events and the displayed month are stored in the app's shared container on the device. The app does not send them off the device (they may be included in your iPhone backups).

Sharing. There is no developer server. The app communicates only with Google (sign-in and the Google Calendar API) and never shares or sells your data.

Deletion. "Sign out" in the app deletes the stored tokens and events and revokes the app's access. You can also revoke access at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact. Please use GitHub Issues.
